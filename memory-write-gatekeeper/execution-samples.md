# memory-write-gatekeeper 执行样本记录模板

用途：记录一次真实“写入前审查”过程，作为回归验证样本。

## 建议记录字段
- 日期
- 原始信息
- 是否建议写入
- 是否需要确认
- 是否检测到冲突
- 是否涉及敏感信息
- 最终审查结论
- 后续写入层级建议
- 结果质量评估
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 原始信息：
- 是否建议写入：是 / 否
- 是否需要确认：是 / 否
- 是否检测到冲突：是 / 否
- 是否涉及敏感信息：是 / 否
- 最终审查结论：通过 / 拦截 / 需确认 / 冲突待确认
- 后续写入层级建议：daily / topic / GLOBAL / none
- 结果质量评估：好 / 一般 / 差
- 备注：
```
