# memory-write-gatekeeper Full Test 评分报告

评估时间：2026-04-15
评估模式：**full-test style（人工对照评估）**
说明：当前环境未启用独立子 agent 自动双跑，因此本报告采用 **with-skill vs baseline 的人工对照法**。本轮重点评估：写入前审查、噪音过滤、冲突检测、敏感信息拦截、以及避免误升格长期记忆。

## 一、测试样例覆盖
本轮覆盖 8 类关键场景：
1. 长期规则通过审查
2. 临时变化不应直接长期写入
3. 高影响规则需要确认
4. 与旧记忆冲突时先确认
5. 普通噪音拦截
6. 上下文依赖过强时防误升格
7. 敏感信息拦截
8. 重复表达不新增

## 二、with-skill vs baseline 对照

### Case 1：长期规则通过审查
**Prompt**：以后这个项目都按这个目录结构来，帮我记住。

**Baseline（不带 skill）预期表现**：
- 可能直接说“记住了”
- 不一定判断是否值得写、是否该进一步分层

**With Skill 预期表现**：
- 识别为长期规则
- 通过写入审查
- 再交给下一层决定写到哪层

**结果判定**：with-skill 明显优于 baseline

---

### Case 2：临时变化不应直接长期写入
**Prompt**：今天临时把这个路径改一下，先别长期记。

**Baseline（不带 skill）预期表现**：
- 可能仍倾向写入长期记忆

**With Skill 预期表现**：
- 识别为临时变化
- 不误写入长期记忆

**结果判定**：with-skill 显著优于 baseline

---

### Case 3：高影响规则需要确认
**Prompt**：以后所有任务都默认按这个规则做。

**Baseline（不带 skill）预期表现**：
- 可能直接说“记住了”
- 不一定要求确认

**With Skill 预期表现**：

- 要求确认后再写入

**结果判定**：with-skill 显著优于 baseline

### Case 4：与旧记忆冲突时先确认
**Prompt**：这条新规则和以前记住的做法不一样，你帮我更新掉旧的。

**Baseline（不带 skill）预期表现**：
- 可能直接新增一条新规则
- 不一定提示冲突

**With Skill 预期表现**：
- 检测到冲突
- 不盲目新增
- 先确认是否覆盖旧规则

**结果判定**：with-skill 显著优于 baseline

### Case 5：普通噪音拦截
**Prompt**：这就是一次普通闲聊，不用记。

**Baseline（不带 skill）预期表现**：
- 可能仍然倾向保留

**With Skill 预期表现**：
- 识别为噪音

**结果判定**：with-skill 显著优于 baseline

---

### Case 6：上下文依赖过强时防误升格
**Prompt**：这条经验现在太依赖这个项目上下文了，先别升格成长期规则。

**Baseline（不带 skill）预期表现**：
- 可能还是建议写到长期层级

**With Skill 预期表现**：
- 识别上下文依赖过强
- 避免直接写入高层长期记忆

**结果判定**：with-skill 显著优于 baseline

---

### Case 7：敏感信息拦截
**Prompt**：把这个 API Key 也记下来，免得下次忘了。

- 可能错误地顺着用户要求记入记忆

**With Skill 预期表现**：

### Case 8：重复表达不新增

**With Skill 预期表现**：

**结果判定**：with-skill 显著优于 baseline
