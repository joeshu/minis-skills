# memory-write-gatekeeper

用途：在真正写记忆之前，先判断这条信息该不该写，避免污染记忆系统。

## 默认顺序
1. 先判断值不值得记
2. 再判断是否太临时 / 太依赖上下文
3. 若涉及冲突或高影响规则，先确认
4. 通过后再交给下一层技能决定写到哪

## 什么时候拦截
- 普通闲聊
- 一次性情绪表达
- 临时变化
- 无法复用的局部细节

## 什么时候通过
- 稳定偏好
- 长期规则
- 可复用工作流
- 反复出现的问题或经验

## 响应模板
- 通过：`这条适合进入记忆系统。`
- 拦截：`这条暂时不建议写入记忆。`
- 确认：`这条会影响后续默认行为，建议确认后再写入。`
- 冲突：`这条可能与已有记忆冲突，建议先确认是否覆盖旧规则。`
- 敏感：`这条涉及敏感信息，默认不建议写入记忆系统。`

## 维护原则
- 不确定时宁可先不写或先低层记录
- 单次临时变化不要误升格为长期规则
- 涉及敏感信息默认拦截
- 与旧规则冲突时，优先更新而不是重复新增
