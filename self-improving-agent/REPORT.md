## 二、with-skill vs baseline 对照

### Case 1：失败记录
**Prompt**：这个命令失败了，而且问题挺隐蔽，帮我记一下以后别再踩。

**Baseline（不带 skill）预期表现**：
- 可能简单说“记一下”
- 不一定区分 error / learning
- 不一定判断记录层级

**With Skill 预期表现**：
- 识别为值得记录
- 判断写入 error / learning
- 默认写技能区

**结果判定**：with-skill 明显优于 baseline

---

### Case 2：用户纠正
**Prompt**：你刚才理解错了，我纠正你一下，这条以后记住。

**Baseline（不带 skill）预期表现**：
- 可能只口头承认
- 不一定形成结构化 learning

**With Skill 预期表现**：
- 识别为用户纠正
- 记录为 learning
- 默认不急着升格长期记忆

**结果判定**：with-skill 明显优于 baseline

---

### Case 3：噪音过滤
**Prompt**：这只是一次普通闲聊，不用记。

**Baseline（不带 skill）预期表现**：
- 可能仍然倾向“都记下来”

**With Skill 预期表现**：
- 明确识别为不值得记录
- 过滤掉噪音

**结果判定**：with-skill 显著优于 baseline

---

### Case 4：提升到公共区
**Prompt**：这个经验已经在多个项目里反复出现了，应该变成公共规则。

**Baseline（不带 skill）预期表现**：
- 可能只建议“记下来”
- 不一定区分当前层级与公共区

**With Skill 预期表现**：
- 识别为跨项目复用
- 建议提升到公共区

**结果判定**：with-skill 明显优于 baseline

---

### Case 5：提升到 Minis 长期记忆
**Prompt**：这个规则以后所有任务都适用，帮我作为长期规则记住。

**Baseline（不带 skill）预期表现**：
- 可能直接说“记住了”
- 不一定判断是否真的足够稳定

**With Skill 预期表现**：
- 识别为可能的长期稳定规则
- 建议提升到 Minis 长期记忆
- 但仍强调需满足稳定性条件

**结果判定**：with-skill 明显优于 baseline

---

### Case 6：项目级记录
**Prompt**：这是这个项目特有的问题，记到项目自己的 learnings 里。

**Baseline（不带 skill）预期表现**：
- 可能还是写到通用技能区

**With Skill 预期表现**：
- 识别为项目级问题
- 建议写到项目级 `.learnings/`

**结果判定**：with-skill 明显优于 baseline

---

### Case 7：复发问题去重更新
**Prompt**：这个坑我已经连续遇到三次了，你别新建重复条目，按复发问题处理。

**Baseline（不带 skill）预期表现**：
- 容易继续重复新增相似条目

**With Skill 预期表现**：
- 识别为复发问题
- 优先更新已有条目
- 不制造重复噪音

**结果判定**：with-skill 显著优于 baseline

---

### Case 8：避免过度升格
**Prompt**：这条经验现在还只在这个项目里成立，先别升格成全局长期规则。

**Baseline（不带 skill）预期表现**：
- 可能仍会建议升格到公共区或长期记忆

**With Skill 预期表现**：
- 识别尚未具备全局稳定性
- 保留在项目级或公共区观察，不误升格

**结果判定**：with-skill 显著优于 baseline
