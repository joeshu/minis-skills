# self-improving-agent

用途：把失败、纠正、知识过时、最佳实践与功能请求整理成可复用学习记录，并控制好写入层级，避免污染长期记忆。

## 默认顺序
1. 先判断值不值得记
2. 默认先写技能区 `data/`
3. 有明确项目上下文时可写项目级 `.learnings/`
4. 跨项目复用后再提升到 `data/public/`
5. 真正稳定后再考虑写入 Minis 长期记忆

## 什么时候建议记录
- 命令/操作失败且非显然
- 用户纠正
- 知识过时
- 外部 API / 工具失败
- 形成了更优可复用方案
- 同类问题反复出现

## 什么时候不建议记录
- 普通闲聊
- 一次性小失误
- 无复用价值细节
- 用户明确说不要记录

## 记录类别
- `learning`
- `error`
- `feature`

## 提升原则
- 跨项目可复用 → 公共区
- 能浓缩成长期规则 → Minis 长期记忆
- 临时变化 / 一次性特例 → 不要急着提升
- 复发但仍依赖具体项目上下文 → 先公共区，不急着写 Minis 记忆

## 复发处理
- 相似问题重复出现时，优先更新已有条目而不是重复新增
- 若已是公共区规则，再次出现应先考虑更新复发次数与适用范围
