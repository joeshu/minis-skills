# self-improving-agent 执行样本

用途：记录一次真实 learning / error / feature / testing 决策过程，作为回归验证样本，并显式区分正式经验与测试验证记录。

## 建议记录字段
- 日期
- 用户原始场景
- 判定类别（learning / error / feature / testing / ignore）
- 是否值得记录
- 是否属于测试/验证记录
- 记录层级（测试层 / 技能区 / 项目级 / 公共区 / Minis 记忆）
- 是否为复发问题
- 是否发生提升
- 是否存在公共区误提升风险
- 最终结果质量评估
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 用户原始场景：
- 判定类别：learning / error / feature / testing / ignore
- 是否值得记录：是 / 否
- 是否属于测试/验证记录：是 / 否
- 记录层级：测试层 / 技能区 / 项目级 / 公共区 / Minis 记忆
- 是否为复发问题：是 / 否
- 是否发生提升：是 / 否
- 是否存在公共区误提升风险：是 / 否
- 最终结果质量评估：好 / 一般 / 差
- 备注：
```

## 真实样本建议覆盖
1. 隐蔽失败记录
2. 用户纠正记录
3. 普通噪音过滤
4. 项目级学习记录
5. 复发问题更新而非重复新增
6. 正式公共区提升
7. 测试/联调记录正确落到测试层
8. 入库前发现数据层需清洗，改为只提交脚本/规则文档
