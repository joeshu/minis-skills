# CHANGELOG

## 0.4.0
- 将 `nuwa-open-minis` 从基础兼容版提升为完整技能系统包。
- 新增 `README.md`、`REPORT.md`、`test-prompts.md`、`execution-samples.md`。
- 明确项目级产物生成能力，不再局限于单个 `SKILL.md`。

## 0.3.0
- 吸收原版女娲的关键方法论：材料模式判断、心智模型三重筛选、提炼检查点、表达 DNA、Response Workflow、增量更新逻辑。
- 强化“本地材料优先、诚实边界优先、产物优先”。

## 0.2.0
- 增加 Open Minis 专用触发模板。
- 增加最小执行闭环：定名 → 建目录 → 写 `SKILL.md` → 给路径 → 再输出正文。
- 增加禁止停留在说明层的明确约束。

## 0.1.0
- 初始版本。
- 目标：在 Open Minis 中稳定执行“材料蒸馏 → 认知框架提炼 → 生成可运行 `SKILL.md`”。
