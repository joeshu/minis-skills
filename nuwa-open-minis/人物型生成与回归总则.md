# 人物型生成与回归总则

## 目标
本文件负责承接 `nuwa-open-minis` 中人物型任务的专用高质量规则，避免主 `SKILL.md` 继续膨胀。

## 适用范围
适用于：
- 真实人物视角型 Skill
- 专家 / 创始人 / 学者 / 管理者视角型 Skill
- 需要高研究压强、强人物感、强张力保留的人物型任务

## 核心原则
1. 人物型 Skill 的目标不是语录合集，而是可运行的人物认知操作系统。
2. 先理解其如何判断、如何切框架、如何拒绝问题，再考虑表达风格。
3. 宁可诚实保守，也不要靠少量材料硬造完整人格。
4. 宁可保留张力、争议、失败与代价，也不要把人物抹平成平滑模板。
5. 第一次生成默认只是可运行初稿，不默认等于收敛版。

## 高质量蒸馏要求
### 1. 多源交叉
优先综合：
- 本人长文 / 著作
- 访谈 / 播客 / 问答
- 社交表达 / 公开发言
- 决策记录 / 行动案例
- 外部批评 / 争议 / 他者视角
- 时间线 / 阶段变化

### 2. 去语录化
一句精彩的话不能自动升级为核心模型。
只有当它具备：
- 跨场景复现
- 生成力
- 排他性

才适合进入主骨架。

### 3. 证据挂钩
关键模型、关键判断、关键张力不能全部外包给 `research-summary.md`。
主 `SKILL.md` 本身要让读者感到这些结论是从材料里长出来的。

### 4. 人物锚点
人物锚点至少尽量覆盖三层：
- 传记锚点
- 认知锚点
- 活体锚点

详见：`人物锚点分层机制.md`

### 5. 表达 DNA
表达 DNA 不应只停留在词汇和口气，还应尽量进入：
- 起手动作
- 切框架动作
- 拒答动作
- 节奏动作
- 叙事装置

详见：`表达DNA动作层机制.md`

### 6. 张力进入主骨架
以下内容不应只埋在附录：
- 争议
- 失败
- 反差
- 未解决张力
- 公开主张与行动之间的落差

### 7. 高争议 / 高表演性 / 高现实后果人物
对这类人物：
1. 默认优先提炼动作机制，不先提炼口气
2. 现实后果应直接进入主结构
3. 先判断更合理的可生成形态是：
   - 视角型 Skill
   - 动作机制分析器
   - 风险人物分析器
4. 生成前先写出“动作层起手骨架”；若写不出起手动作 / 切框架动作 / 改写动作，则默认仍处在总结报告假像风险区

若角色扮演器形态容易滑向站队稿、辩护稿、口气模仿稿，应优先后两者。

## 收敛原则
- 宁可保留 3-5 个稳定模型，也不要凑出 10 个浅层观点
- 宁可明确边界，也不要伪装完整人格全貌
- 宁可少写但把关键证据挂上，也不要只剩漂亮抽象结论
- 宁可留补料入口，也不要为了像成品而压扁人物

## 回归机制
当人物型样本已可运行，但与成熟样本相比仍有明显差距时：
1. 先做并排评审
2. 每轮只抓 1-3 个最大差距
3. 优先改主 `SKILL.md`
4. 每轮写清仍差什么
5. 不要把真实样本回归再次抽象扩成总规则堆积

详见：`人物型样本回归优化清单.md`

## 假像识别
人物型任务封板前，优先用：
- `人物型假像识别清单.md`

重点检查：
- 语录合集假像
- 总结报告假像
- 气质模仿假像
- 成功学模板假像
- 研究外包假像
- 完美结构假像

如果假像明显成立，优先先修主文件研究压强、人物锚点、张力主骨架和典型问题开口，而不是继续扩章节。

## 持续喂料与增量收敛
人物型任务进入多轮补料阶段时，默认走增量收敛，不把每轮补料都视为重写。

详见：`人物型持续喂料与增量收敛机制.md`
