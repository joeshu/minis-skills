# 配套产物与技能包生成规则

## 目标
本文件负责统一 `nuwa-open-minis` 在 `SKILL.md` 之外的配套产物生成规则，避免主文件继续承载过多产物层细则。

## 三层优先级
### 1. 必需
默认始终先确保：
- `SKILL.md`

### 2. 常用
以下文件只在明显需要时补：
- `research-summary.md`
- `test-prompts.md`

### 3. 长期维护型
只有当用户明确要长期维护、交接、追溯或完整技能包时，再考虑：
- `README.md`
- `REPORT.md`
- `sources-index.md`
- `reference-map.md`
- `appendix-sources.md`

## 最小生成规则
### 用户只说“造一个 skill”
至少确保生成：
- `SKILL.md`

### 用户说“先给我调研 / 帮我压测”
优先考虑补：
- `research-summary.md`
- `test-prompts.md`

### 用户说“做成完整技能包 / 便于后续维护”
再补长期维护型文件。

## 生成原则
1. 先把主 Skill 跑通，再补周边文件。
2. 配套文件服务于长期可用，不服务于看起来完整。
3. 小任务宁可少文件但清楚，不机械补齐全家桶。
4. 若研究痕迹对可信度至关重要，优先补 `research-summary.md` 或 `sources-index.md`。
