# 新样本回归执行计划（第一轮）

## 目标
按当前 `nuwa-open-minis` 的后续优化路线，正式进入“真实样本回归驱动优化”模式，而不是继续做结构性补强。

## 本轮执行原则
1. 不继续扩主文件结构。
2. 用新样本直接压测当前最终版 `nuwa-open-minis`。
3. 每轮只抓 1 个最大假像点。
4. 默认只优先产出 `SKILL.md` 与必要研究痕迹。
5. 本轮先做第一轮，不并行开 3 个样本，避免再次扩散。

## 第一轮样本选择标准
优先选择同时满足以下条件的对象：
- 与现有样本风格差异大
- 低表演性但高方法密度
- 创业 / 投资之外人物
- 有足够公开材料可支撑人物型蒸馏
- 适合暴露“活体锚点不足 / 只列模型不长动作 / 写成总结报告”的风险

## 第一轮推荐样本方向
### 主推荐
- **学者 / 思想家型人物**

原因：
- 与现有高表演性 / 创业者样本拉开差异
- 更容易检验当前版女娲是否会滑向“总结报告式人物介绍”
- 更容易暴露：
  - 活体锚点不足
  - 只有抽象模型，没有人物动作
  - 写得正确但不活

### 暂不优先
- 再做高争议高表演性人物
- 再做创业 / 投资人物
- 再做材料过薄的冷门对象

## 本轮只抓的最大假像点
### 假像点：总结报告假像
本轮只重点检查这一项：
- 产物是否像“关于某人物的总结报告”
- 而不是“可运行的人物认知操作系统”

### 观察信号
若出现以下任一现象，视为命中：
- 全文高度抽象，缺少人物现场感
- 模型条目都对，但读不出这个人如何发生作用
- 有观点、有判断，但没有起手动作 / 切框架动作 / 拒答动作
- 看起来像一篇高质量人物综述，而不是可运行 Skill

## 本轮执行动作
1. 选定 1 个学者 / 思想家型真实样本
2. 用当前版 `nuwa-open-minis` 跑完整第一版
3. 只做“总结报告假像”检查
4. 写回一份回归记录：
   - 哪里开始变假
   - 是否需要点状回写
   - 若要回写，只回写 1 个点

## 回写约束
- 不因 1 次样本回归就重新扩结构
- 不因出现多个问题就同时修多个点
- 不为了显得完整而补 README / REPORT / 完整技能包

## 成功标准
本轮不是追求直接产出完美样本，而是验证：
- 当前版女娲是否真的比之前更容易长出“像人物”的主骨架
- 是否比之前更少滑向总结报告假像
- 是否已经把结构优化阶段切换到样本回归阶段
