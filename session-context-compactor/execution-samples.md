# session-context-compactor 执行样本记录模板

用途：记录一次真实上下文压缩过程，作为 full test 与回归验证样本。

## 建议记录字段
- 日期
- 用户原始请求
- 模式（A / B）
- 是否跨会话
- 项目类型（代码 / 技能 / 文档 / 混合）
- 摘要输出路径
- 必要保留文件清单
- 是否写入 shared
- 是否需要删除确认
- 最终是否删除历史会话
- 结果质量评估
- 风险备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 用户原始请求：
- 模式：A / B
- 是否跨会话：是 / 否
- 项目类型：代码 / 技能 / 文档 / 混合
- 摘要输出路径：
- 必要保留文件清单：
- 是否写入 shared：是 / 否
- 是否需要删除确认：是 / 否
- 最终是否删除历史会话：是 / 否
- 结果质量评估：好 / 一般 / 差
- 风险备注：
```

## 评分用途
后续可据此观察：
- 哪类项目最容易漏保留文件
- 哪些摘要最容易过长
- 哪些场景最容易误删历史会话前提不足
