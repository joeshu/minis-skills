# 芒格样本二轮验证发现

## 发现
在芒格样本上，第二轮点状修正后，表达 DNA 已通过，但人物锚点检测仍未通过。

## 真实原因
不是芒格版本没有锚点，而是脚本中的锚点检测模式仍然偏向前两个样本（张一鸣 / Paul Graham），对芒格这种“巴菲特搭档 / 伯克希尔 / Daily Journal / Too Hard / 激励结构”型人物锚点识别不足。

## 说明
1. 第三人物样本继续暴露出：脚本工具必须持续经过多样化人物样本回归
2. `quality_check_open_minis.py` 的锚点检测逻辑应继续保持“多样本泛化”思路，而不是只扩个别人物词表
3. 芒格样本最有价值的系统贡献之一，是进一步证明了“人物锚点”不能被简化为少量固定模板

## 处理
已继续把芒格高信息密度锚点纳入检测模式，下一步应复跑质检并进入并排评审。
