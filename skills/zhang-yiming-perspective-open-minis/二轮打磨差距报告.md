# 张一鸣重做版二轮打磨差距报告

## 本轮新增学习到的原版素材重点
1. 张一鸣很多关键表达不是“大道理”，而是从具体小事进入：睡觉、跑步、404 页面、招聘 JD、传记阅读。
2. 他不是简单“理性”，而是会把情绪、人才、职业、亲密关系都翻译成工程语言：向量、近似最优解、过拟合、逃逸速度。
3. 他的关键矛盾不是装饰项，而是主骨架：算法中性 vs 平台责任、去政治化 vs 政治现实、反控制 vs 关键时刻集权。
4. 他对“成功学”本身有警惕，这意味着人物型 Skill 不能把他写成一套可复制鸡汤。

## 本轮对重做版的主要增强
- 补了更具体的身份锚点
- 在 5 个核心模型下补了证据锚点
- 强化了表达 DNA 的微动作层约束
- 把时间线从履历表改成更有转折感的结构
- 增加了“主文件里要看见研究痕迹”的自检要求

## 仍与原版存在的差距
1. **模型下的证据仍偏摘要化**
   - 还没有达到原版那种“原话 / 事件 / 局限”三联结构密度
2. **表达 DNA 仍可继续细化**
   - 比如：轻微讽刺的边界、他如何拒绝抽象身份定义、如何在被道德追问时切框架
3. **来源自包含仍不够强**
   - 重做版目录还没有真正带上研究母本，只是索引到原版研究目录
4. **人物活体感仍略弱于原版**
   - 现在比上一版好多了，但原版仍更像“已经被长期喂养过的人物”

## 对 nuwa-open-minis 的进一步启发
人物型 Skill 若想逼近原版质量，除了前一轮规则，还应继续强化：
1. 尽量多用“具体小事 → 底层原则”而不是直接列原则
2. 高价值人物的工程语言 / 比喻系统 / 习惯动作，要进入表达 DNA，而不是只写抽象风格
3. 若人物本身强烈反感被成功学模板化，Skill 里应加入“反神话化约束”
4. 高质量人物型 Skill 不只要写“怎么想”，还要写“他拒绝怎么想、拒绝在哪个框架里回答”
