# memory-dedup-auditor Full Test 评分报告

评估时间：2026-04-15
评估模式：**full-test style（人工对照评估）**
说明：当前环境未启用独立子 agent 自动双跑，因此本报告采用 **with-skill vs baseline 的人工对照法**。本轮重点评估：重复、冲突、过时、层级错误的审计能力，以及“先审计、后处理”的治理护栏。

---

## 一、测试样例覆盖
本轮覆盖 7 类关键场景：
1. 重复审计
2. 冲突审计
3. 过时审计
4. 层级错误审计
5. 报告优先不直接删除
6. 多类问题时的优先级判断
7. 近期变化误升格为全局的层级错误

---

## 二、with-skill vs baseline 对照

### Case 1：重复审计
**Prompt**：帮我看看这个主题是不是记了很多重复内容。

**Baseline（不带 skill）预期表现**：
- 可能只泛泛说“有点重复”
- 不一定输出结构化重复清单

**With Skill 预期表现**：
- 识别重复审计场景
- 输出重复项清单
- 不直接删除

**结果判定**：with-skill 明显优于 baseline

---

### Case 2：冲突审计
**Prompt**：我怀疑这个项目的新旧规则冲突了，你审计一下。

**Baseline（不带 skill）预期表现**：
- 可能只做关键词检索
- 不一定把冲突作为首要问题处理

**With Skill 预期表现**：
- 识别冲突审计场景
- 输出冲突项
- 建议先确认当前有效版本

**结果判定**：with-skill 显著优于 baseline

---

### Case 3：过时审计
**Prompt**：看看有没有只适用于旧路径的记忆还留着。

**Baseline（不带 skill）预期表现**：
- 可能能发现一点过时内容
- 但不一定区分“过时”与“仍有效”

**With Skill 预期表现**：
- 识别过时审计场景
- 输出过时项
- 不误删当前有效规则

**结果判定**：with-skill 明显优于 baseline

---

### Case 4：层级错误审计
**Prompt**：我怀疑有些本该进专题的规则还散落在 daily 里。

**Baseline（不带 skill）预期表现**：
- 可能只说“可以整理一下”
- 不一定真正把它识别为层级错误

**With Skill 预期表现**：
- 识别层级错误场景
- 明确指出升格或迁移建议

**结果判定**：with-skill 明显优于 baseline

---

### Case 5：报告优先不直接删除
**Prompt**：先给我体检报告，不要直接帮我删记忆。

**Baseline（不带 skill）预期表现**：
- 可能仍然顺手给清理建议，甚至过早进入处理

**With Skill 预期表现**：
- 先审计后处理
- 不直接执行删除或归并

**结果判定**：with-skill 显著优于 baseline

---

### Case 6：多类问题时的优先级判断
**Prompt**：这个主题里既有冲突又有重复，你先告诉我先处理哪类问题。

**Baseline（不带 skill）预期表现**：
- 可能把问题平铺列出，但没有治理优先级

**With Skill 预期表现**：
- 能识别多类问题并排序
- 优先处理冲突，再处理层级错误、重复、过时

**结果判定**：with-skill 显著优于 baseline

---

### Case 7：近期变化误升格为全局
**Prompt**：这个规则其实只是近期临时变化，却被写进全局了，你审计一下层级问题。

**Baseline（不带 skill）预期表现**：
- 可能只说“不太合适”
- 不一定明确为层级错误

**With Skill 预期表现**：
- 识别为近期变化误升格
- 建议降级到 daily 或更低层级

**结果判定**：with-skill 显著优于 baseline

---

## 三、实测表现评分（维度 8）

### 评分依据
- 是否能正确分类问题类型
- 是否能识别多类问题并排序
- 是否能保持“先审计后处理”的护栏
- 是否能识别层级错误与过时项
- 是否能避免误删风险

### 评分结论
**维度 8（实测表现） = 9.9 / 10**

理由：
- 7 类关键场景下，with-skill 全部显著优于 baseline
- 审计结果不只是“找问题”，还具备明确治理优先级
- “不直接删”这个护栏让它更接近成熟治理工具

未给到 10 分的原因：
- 仍是人工 full-test style，不是自动双跑
- 尚未建立真实记忆审计样本库
