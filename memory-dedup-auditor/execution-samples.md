# memory-dedup-auditor 执行样本记录模板

用途：记录一次真实记忆审计过程，作为回归验证样本。

## 建议记录字段
- 日期
- 审计范围
- 命中主题/关键词
- 重复项数量
- 冲突项数量
- 过时项数量
- 层级错误项数量
- 建议优先处理项
- 是否进入后续整理
- 结果质量评估
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 审计范围：
- 命中主题/关键词：
- 重复项数量：
- 冲突项数量：
- 过时项数量：
- 层级错误项数量：
- 建议优先处理项：
- 是否进入后续整理：是 / 否
- 结果质量评估：好 / 一般 / 差
- 备注：
```
