# memory-dedup-auditor

用途：扫描记忆系统中的重复、冲突、过时或层级错误内容，先给审计报告，再决定是否整理。

## 默认顺序
1. 先审计
2. 再分类
3. 再给建议动作
4. 默认不直接删除

## 主要问题类型
- 重复
- 冲突
- 过时
- 层级错误

## 默认输出
- 问题摘要
- 分类清单
- 建议动作

## 建议动作优先级
1. 冲突
2. 层级错误
3. 重复
4. 过时

## 审计边界
- 默认只出报告，不直接删
- 如需真正整理，再交给其他记忆治理技能

## 与其他技能的关系
- 审计完后，如用户同意，再交给 `open-minis-memory-store` 做整理
