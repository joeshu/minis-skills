# open-minis-handoff-orchestrator 执行样本记录模板

用途：记录一次真实“前中后闭环编排”过程，作为回归验证样本。

## 建议记录字段
- 日期
- 用户原始请求
- 是否先命中专题记忆
- 执行中新规则写入到哪层
- 是否生成 handoff
- 是否写入 shared
- 是否要求删除历史会话
- 是否触发删除确认
- 是否调用记忆归并
- 最终结果质量评估
- 风险备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 用户原始请求：
- 是否先命中专题记忆：是 / 否
- 执行中新规则写入层级：专题 / GLOBAL / daily / 无
- 是否生成 handoff：是 / 否
- 是否写入 shared：是 / 否
- 是否要求删除历史会话：是 / 否
- 是否触发删除确认：是 / 否
- 是否调用记忆归并：是 / 否
- 最终结果质量评估：好 / 一般 / 差
- 风险备注：
```
