# open-minis-handoff-orchestrator 执行样本记录模板

用途：记录一次真实“前中后闭环编排”过程，作为回归验证样本。

## 建议记录字段
- 日期
- 用户原始请求
- 是否先命中专题记忆
- 执行中新规则写入到哪层
- 是否生成 handoff
- 是否写入 shared
- 是否要求删除历史会话
- 是否触发删除确认
- 是否调用记忆归并
- 最终结果质量评估
- 风险备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 用户原始请求：
- 是否先命中专题记忆：是 / 否
- 执行中新规则写入层级：专题 / GLOBAL / daily / 无
- 是否生成 handoff：是 / 否
- 是否写入 shared：是 / 否
- 是否要求删除历史会话：是 / 否
- 是否触发删除确认：是 / 否
- 是否调用记忆归并：是 / 否
- 最终结果质量评估：好 / 一般 / 差
- 风险备注：
```

- 是否先命中专题记忆：否（本轮重点不在专题命中，而在连续性系统本身）
- 执行中新规则写入层级：无
- 是否生成 handoff：是
- 是否写入 shared：是
- 是否要求删除历史会话：否
- 是否触发删除确认：否
- 是否调用记忆归并：否
- 最终结果质量评估：好
- 风险备注：真实回归确认这条系统在“跨会话继续”场景下，应该优先保证 shared handoff 入口稳定，而不是优先扩写更多规则。
