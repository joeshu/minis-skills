## 五、当前仍未完全覆盖的边界

### 1. 真实大规模专题样本不足
- 当前已有专题样本库，但规模还不大
- 不同风格、不同长度、不同命名习惯的真实专题还不够多

### 2. 真实 daily / GLOBAL 混合污染样本不足
- 目前已有规则型验证
- 但真实历史污染场景还可以更多

### 3. 记忆系统长期漂移监测仍未建立
- 已有回归记录
- 但还没有“周期性自动对比过去版本误判率”的长期机制

---

## 六、下一阶段最值方向

### P1：扩专题样本库
优先补：
- 更多项目专题
- 更多平台专题
- 更多方法论专题
- 不同命名风格样本

### P2：补混合污染案例
重点构造：
- daily 和专题重复
- GLOBAL 和专题冲突
- 多专题边界重叠

### P3：建立阶段性回归基线
建议每做完一轮大改后：
- 固定跑一组回归样本
- 更新阶段报告
- 对比误判/漏判

**一套有技能、有样本、有回归、有文档、有治理顺序的长期记忆治理框架。**
