# 记忆系统使用手册

生成时间：2026-04-15

## 一、怎么用这套记忆技能
这套技能不是后台自动守护程序，而是：
- 你可以**直接点名技能**
- 也可以**直接说自然语言意图**
- 我负责根据意图自动匹配合适的记忆技能

简单理解：
- 你负责说需求
- 我负责选对技能并按顺序调用

---

## 二、最常见的 6 类意图

### 1. 继续旧项目 / 旧主题时，先查长期规则
你可以说：
- `继续这个项目，先按过去约定来`
- `先查这个主题的长期记忆`
- `先看这个项目以前的规则`

通常会触发：
- `memory-topic-router`

作用：
- 先判断应该先读专题记忆、`GLOBAL.md` 还是 daily memory

---

### 2. 想把一条新信息记住之前，先判断值不值得记
你可以说：
- `这条值不值得记`
- `这条以后要不要记住`
- `先判断这条该不该进记忆`

通常会触发：
- `memory-write-gatekeeper`

作用：
- 先拦截噪音、一次性变化、敏感信息、冲突覆盖风险

---

### 3. 想知道这条信息该写到哪层记忆
你可以说：
- `这条写专题还是全局`
- `这条只记今天还是长期保留`
- `这条该写到哪一层`

通常会触发：
- `memory-layer-governor`

作用：
- 决定写到：
  - 不记录
  - daily memory
  - 专题记忆
  - `GLOBAL.md`

---

### 4. 觉得某个主题的记忆太乱了，先做体检
你可以说：
- `审计一下这个主题记忆`
- `看看有没有重复和冲突`
- `这个主题记忆是不是乱了`

通常会触发：
- `memory-dedup-auditor`

作用：
- 先查重复、冲突、过时、层级错误
- 默认只出报告，不直接删

---

### 5. 想把一个主题的旧记忆整理成主记忆
你可以说：
- `把这个主题的记忆整理成一条`
- `删除旧的重复记忆，只留主记忆`
- `把这些零散记忆归并一下`

通常会触发：
- `open-minis-memory-store`

作用：
- 归并旧记忆
- 清理重复项
- 保留主记忆

---

### 6. 想整体维护这套记忆系统
你可以说：
- `帮我维护一下整个记忆系统`
- `把记忆系统整理顺一点`
- `按合适顺序治理一下记忆`

通常会触发：
- `memory-system-maintainer`

作用：
- 作为总管，决定先审查、先分层、先审计还是先归并

---

## 三、最短实战流程

### 场景 A：继续某项目
你说：
> `继续这个项目，先按过去约定来`

我通常会：
1. 先走 `memory-topic-router`
2. 命中对应专题后再继续任务

---

### 场景 B：你想记一条新规则
你说：
> `以后这个项目都按这个目录结构来，帮我记住`

我通常会：
1. 先走 `memory-write-gatekeeper`
2. 再走 `memory-layer-governor`
3. 最后才真正写入

---

### 场景 C：你觉得主题记忆越来越乱
你说：
> `这个主题记忆有点乱，帮我整理一下`

我通常会：
1. 先走 `memory-dedup-auditor`
2. 出体检报告
3. 如你同意，再走 `open-minis-memory-store`

---

### 场景 D：你想整体治理
你说：
> `帮我维护一下整个记忆系统`

我通常会：
1. 走 `memory-system-maintainer`
2. 由它再编排其他子技能

---

## 四、你可以直接点名，也可以不点名

### 直接点名
例如：
- `用 memory-topic-router 先查这个项目的专题记忆`
- `用 memory-write-gatekeeper 看这条该不该记`
- `用 memory-layer-governor 判断这条写哪层`

### 不点名，直接说意图
例如：
- `继续这个项目，先查过去约定`
- `这条值不值得记`
- `审计一下这个主题记忆`

我会自动匹配对应技能。

---

## 五、推荐记忆技能地图

| 需求 | 优先技能 |
|---|---|
| 先读哪类记忆 | `memory-topic-router` |
| 这条该不该写 | `memory-write-gatekeeper` |
| 这条写哪层 | `memory-layer-governor` |
| 查重复/冲突/过时 | `memory-dedup-auditor` |
| 整理旧记忆 | `open-minis-memory-store` |
| 维护整套系统 | `memory-system-maintainer` |

---

## 六、一句话总结
- **继续旧任务先查规则** → `memory-topic-router`
- **写之前先审查** → `memory-write-gatekeeper`
- **决定写哪层** → `memory-layer-governor`
- **记忆乱了先体检** → `memory-dedup-auditor`
- **体检后再归并** → `open-minis-memory-store`
- **整套一起管** → `memory-system-maintainer`
