- 误判点：无
- 改进建议：后续可增加“daily 中保留少量近期增量但去掉重复主体”的样本。

- 实际结果：按当前规则，应结合稳定性与作用范围评分判断：若已跨多次任务复用但仍未完全跨主题，可先升到专题或公共区观察，而不是直接冲到最高层。

- 误判点：无
- 改进建议：后续可增加“复发 3 次但仍强依赖单项目上下文”的样本，继续压测升格边界。
