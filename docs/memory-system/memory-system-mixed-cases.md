# 记忆系统混合污染案例库

用途：收集和构造真实或半真实的“跨层混乱”样本，用于回归测试记忆系统的治理能力。

## 案例类型

### Case A：daily 与专题重复
- 同一条长期规则既存在于专题文件，又在多天 daily memory 中重复出现。
- 目标：验证是否能优先识别为“专题长期规则 + daily 重复噪音”。

### Case B：GLOBAL 与专题冲突
- 某条规则在专题中是“主题内例外”，但在 GLOBAL 中被写成全局原则。
- 目标：验证是否能识别“专题特例不应覆盖全局，或全局不应误写成专题”。

### Case C：临时变化误升格
- 近期临时路径调整或一次性例外被写入 GLOBAL 或专题。
- 目标：验证是否能降级回 daily。

### Case D：多专题边界重叠
- 同一条规则同时看起来像平台专题、工作流专题、项目专题。
- 目标：验证是否能先选最具体专题，再决定是否补读上层专题。

### Case E：主记忆与旧记忆并存失控
- 已有主记忆，但 daily 和记忆文件里仍保留大量旧版本和重复表达。
- 目标：验证审计后是否能优先更新主记忆并清理旧项。
