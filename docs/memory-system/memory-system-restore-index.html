恢复入口

恢复指南 一键恢复命令模板 shared 同步策略 memory-system-git-sync 技能 最终成熟度报告 记忆系统总入口页面

默认恢复仓库地址

https://github.com/joeshu/minis-skills.git

恢复内容分层

1. 技能框架

从 git 恢复核心技能目录、系统 README、地图、手册、报告、回归资料。

2. shared 镜像

从仓库中的 docs/memory-system/ 与 docs/memory-topics/ 恢复共享文档与专题样本。

3. 脱敏 memory 镜像

从 docs/memory-export-sanitized/ 恢复参考副本，但它不等于你的真实个人记忆数据。

4. 真实个人记忆

如有单独备份，再恢复 /var/minis/memory/；这部分默认不直接进 git。

最短恢复顺序

1. clone 仓库
2. 恢复核心技能目录到 /var/minis/skills/
3. 恢复 docs/memory-system/* 到 /var/minis/shared/
4. 恢复 docs/memory-topics/* 到 /var/minis/shared/memory_topics/
5. 如有需要，参考 docs/memory-export-sanitized/ 对照恢复
6. 最后单独恢复真实个人记忆备份

敏感信息边界

  • 原始 /var/minis/memory/ 真实个人记忆默认不直接进 git。
  • git 中保存的是脱敏镜像，用于恢复参考，不是个人真实记忆的完整替代。
  • Token / API Key / 私密信息默认拦截，不进入仓库。
