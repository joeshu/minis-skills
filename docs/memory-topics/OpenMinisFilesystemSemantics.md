# OpenMinis 文件系统语义

## 目的
- 把 OpenMinis 的路径系统正式纳入这套治理体系。
- 让路径不只是存储位置，而是具有明确语义角色。

## 路径语义

### `/var/minis/workspace/`
- 当前任务工作区
- 适合：脚本、草稿、当前任务中间结果、单次任务产物

### `/var/minis/shared/`
- 跨会话共享资产区
- 适合：长期项目文件、规则体系、handoff、可恢复文档、共享数据

### `/var/minis/attachments/`
- 展示与媒体附件区
- 适合：图片、音频、视频、截图、可直接展示给用户的媒体结果

### `/var/minis/memory/`
- 长期记忆区
- 适合：偏好、稳定约定、长期事实
- 不适合：大段产物、临时日志、执行中间态

### Git 仓库镜像
- 发布与恢复层
- 适合：可分享、可恢复、可迁移版本
- 不适合：高频运行态与敏感实时痕迹

### chat
- 即时交互层
- 适合：结论、摘要、提示、路径说明
- 不适合：承担需要长期复用的主要资产

## 语义原则
- 路径代表生命周期，不只是目录。
- 工作区与共享区分离，避免临时产物污染长期资产。
- 记忆区与共享区分离，避免规则系统和个人长期偏好混杂。
- 发布镜像与运行态分离，避免 Git 仓库承担运行态职责。

## 与其他文件的关系
- 本文件提供路径语义基础。
- `ResultPlacementPolicy.md` 基于本文件决定结果落点。
- `ExecutionPriorityMatrix.md` 基于本文件决定执行后产物的承接位置。
