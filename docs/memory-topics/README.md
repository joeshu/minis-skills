# memory_topics 说明

用途：存放真实专题记忆样本，用于：
- 任务执行前专题优先检索
- 记忆系统真实案例回归测试
- 验证专题 / GLOBAL / daily 的边界

## 建议命名
- 项目专题：`<project>.md`
- 平台专题：`github.md`、`bilibili.md`
- 工作流专题：`github-sync.md`
- 方法论专题：`memory-maintenance.md`、`skill-design.md`

## 当前样本
- `github.md`
- `github-sync.md`
- `memory-maintenance.md`
- `skill-design.md`
- `UnifiedVIP.md`

## Bilibili 平台专题样本
- 平台相关任务优先判断是内容检索、下载、账号状态、还是平台规则问题。
- 若是平台长期规则或高频操作，优先查平台专题，再视需要补查具体工作流专题。

## Notion 平台专题样本
- 若任务涉及数据库、页面结构、API 或工作区规则，优先视为 Notion 平台专题。
- 平台规则与具体项目规则分开存放，避免把 Notion 通用规则写入项目专题。

## 上下文压缩方法论专题样本
- 当前会话过长时，优先考虑会话压缩与 handoff，而不是把整段对话当长期记忆。
- 会话摘要与长期记忆要区分：前者服务接续执行，后者服务长期规则。
