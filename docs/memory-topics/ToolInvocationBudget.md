# 工具调用预算

## 目的
- 在 OpenMinis 中，为不同任务提供低成本、低噪音、可验证的默认工具路径。
- 避免为了形式而过度调用工具。

## 核心原则
- 能低成本完成，就不走高成本路径。
- 能直接用专用工具，就不走通用兜底路径。
- 工具调用服从最短可用闭环，而不是追求看起来很全面。

## 默认工具优先级

### 1. 文件读取
- 优先：`file_read`
- 次选：`shell_execute` + 读取命令
- 原则：能直接读文件，就不额外走 shell

### 2. 文件创建与修改
- 新建：`file_write`
- 修改：`file_edit`
- 原则：能结构化写改，就不走 shell 拼接文本

### 3. 网页内容获取
- 优先：可读文本 / 结构化提取路径
- 次选：DOM / JS 辅助
- 末选：截图 / OCR
- 原则：先低成本、可验证路径

### 4. 系统操作与执行
- 优先：`shell_execute`
- 但：先判断是否真的需要执行，而不是为了显得主动而执行

### 5. 记忆读写
- 检索：`memory_get`
- 写入：`memory_write`
- 原则：只在长期有价值时进记忆，不把临时内容塞入长期层

## 预算意识
- 简单任务：0~1 次工具优先
- 中等任务：1~3 次工具优先
- 复杂任务：按阶段调用，但每一步都要说明必要性

## 失控信号
- 为了形式连续调用多个可替代工具
- 能直接回答却还去读很多文件
- 能直接 file_read 却走 shell
- 能直接执行却先长篇解释
