# open-minis-output-governor 执行样本

用途：记录真实输出治理决策，验证结果形式、落盘位置、命名稳定性与聊天摘要控制是否匹配任务需求。

## 建议记录字段
- 日期
- 任务类型
- 用户对输出的要求
- 最终输出形式（聊天 / Markdown / HTML / attachment / 组合）
- 最终落盘位置（shared / workspace / attachments / 无）
- 聊天摘要级别（无 / 最小一句 / 1~3 句 / 完整解释）
- 是否使用稳定命名
- 是否满足用户预期
- 是否存在输出形式错配
- 是否存在存储位置错配
- 备注

## 真实样本建议覆盖
1. 用户只要一句结论，不落盘
2. 用户要 Markdown 报告，并要求后续可复看
3. 用户要 HTML 页面用于展示
4. 用户要跨会话继续使用，正确写入 shared
5. 用户只要当前调试中间产物，正确写入 workspace
6. 用户要直接预览图表，正确写入 attachments
7. 用户同时要聊天总结 + 完整文件
8. 用户明确“不要长聊天解释”，只保留最小摘要
9. 一度想写 shared，但经判断应降级为 workspace
