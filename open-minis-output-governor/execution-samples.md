# open-minis-output-governor 执行样本模板

用途：记录一次真实输出治理决策，验证结果形式、落盘位置与聊天摘要是否匹配任务需求。

## 建议记录字段
- 日期
- 任务类型
- 用户对输出的要求
- 最终输出形式（聊天 / Markdown / HTML / attachment / 组合）
- 最终落盘位置（shared / workspace / attachments / 无）
- 是否给了聊天摘要
- 是否满足用户预期
- 是否存在输出形式错配
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 任务类型：
- 用户对输出的要求：
- 最终输出形式：
- 最终落盘位置：
- 是否给了聊天摘要：是 / 否
- 是否满足用户预期：是 / 否
- 是否存在输出形式错配：是 / 否
- 备注：
```
