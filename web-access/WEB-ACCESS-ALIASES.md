# WEB-ACCESS-ALIASES

## 统一调用别名协议

后续凡是以下表达，默认都按 `web-access` 入口理解：

- 帮我读这个网页
- 帮我看这个网站
- 帮我提取这篇文章
- 帮我总结这个页面
- 帮我去某站找内容
- 帮我在某网站搜索并点进去
- 帮我滚动收集这个页面里的内容

## 默认解释方式

收到此类请求时，默认按以下思路处理：
1. 这是网页任务
2. 优先走 `web-access`
3. 先分流，再匹配站点，再执行
4. 若执行中发现新站点规律，先生成候选经验，再考虑正式沉淀

## 不必显式提 skill 名称

用户无需说“调用 web-access skill”。
只要意图属于网页访问/提取/浏览/收集，默认可直接进入该体系。
