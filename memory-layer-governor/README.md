# memory-layer-governor

用途：决定一条新信息该写到哪一层记忆：专题、GLOBAL、daily，还是不记。

## 默认顺序
1. 先判断值不值得记
2. 不确定稳定性时优先写 daily
3. 主题内长期规则写专题
4. 跨主题长期原则写 `GLOBAL.md`

## 适用场景
- 新规则出现
- 新偏好出现
- 新例外出现
- 某经验似乎值得长期保留
- 想避免记忆污染

## 响应模板
- 不记录：`这条暂时不建议进入记忆系统。`
- daily：`这条更像近期变化，建议先写入 daily memory。`
- 专题：`这条属于主题内长期规则，建议写入对应专题记忆。`
- GLOBAL：`这条是跨主题长期原则，建议写入 GLOBAL.md。`
- 边界：`这条还不够稳定，先不要升格到更高层级。`

## 维护原则
- 不确定时宁可先写 daily
- 单主题长期规则不要误写进 GLOBAL
- 跨主题原则不要误写进专题
- 一次性噪音不进入记忆系统
