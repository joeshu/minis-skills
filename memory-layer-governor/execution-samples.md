# memory-layer-governor 执行样本记录模板

用途：记录一次真实“新信息写入哪层记忆”的判断过程，作为回归验证样本。

## 建议记录字段
- 日期
- 原始信息
- 是否值得记录
- 稳定性判断
- 作用范围判断
- 最终建议层级
- 是否实际写入
- 是否存在边界争议
- 结果质量评估
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 原始信息：
- 是否值得记录：是 / 否
- 稳定性判断：低 / 中 / 高
- 作用范围判断：专题 / 全局 / 近期
- 最终建议层级：不记录 / daily / topic / GLOBAL
- 是否实际写入：是 / 否
- 是否存在边界争议：是 / 否
- 结果质量评估：好 / 一般 / 差
- 备注：
```
