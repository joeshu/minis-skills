# memory-layer-governor Full Test 评分报告

评估时间：2026-04-15
评估模式：**full-test style（人工对照评估）**
说明：当前环境未启用独立子 agent 自动双跑，因此本报告采用 **with-skill vs baseline 的人工对照法**。本轮重点评估：新信息在**已通过写入审查**前提下应写入哪层记忆、何时不该升格，以及如何避免记忆污染。

---

## 一、测试样例覆盖
本轮覆盖 8 类关键场景：
1. 近期变化 → daily
2. 单专题长期规则 → 专题记忆
3. 跨主题长期原则 → GLOBAL
4. 普通闲聊 / 噪音 → 不记录
5. 尚未稳定 → 不升格
6. 单专题长期规则不误写进 GLOBAL
7. 有复用但未完全全局化 → 先低层或公共区观察
8. 一次性排障经验避免污染长期记忆

## 二、with-skill vs baseline 对照

**Prompt**：这只是今天临时改的一个路径，先记一下，但不一定长期有效。

**Baseline（不带 skill）预期表现**：

- 不一定明确 daily 更合适

**With Skill 预期表现**：
