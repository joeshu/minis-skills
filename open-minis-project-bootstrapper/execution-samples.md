# open-minis-project-bootstrapper 执行样本模板

用途：记录一次真实项目骨架生成过程，作为回归验证样本。

## 建议记录字段
- 日期
- 项目名
- 项目类型
- 用户目标（最小骨架 / 长期维护 / 跨会话 / 试验性）
- 是否生成 docs
- 是否生成 handoff 目录
- 是否生成 topic memory stub
- 实际生成文件
- 是否满足用户预期
- 是否存在结构过重或结构不足
- 结果质量评估
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 项目名：
- 项目类型：代码 / 技能 / 文档 / 系统 / 混合
- 用户目标：最小骨架 / 长期维护 / 跨会话 / 试验性
- 是否生成 docs：是 / 否
- 是否生成 handoff 目录：是 / 否
- 是否生成 topic memory stub：是 / 否
- 实际生成文件：
- 是否满足用户预期：是 / 否
- 是否存在结构过重或结构不足：是 / 否
- 结果质量评估：好 / 一般 / 差
- 备注：
```
