# open-minis-project-bootstrapper

用途：为新项目快速建立标准骨架，减少每次手动拼目录结构的成本。

## 默认目标
- 有 README
- 有 REPORT
- 有 test-prompts
- 有 execution-samples
- 需要时有 docs / handoff / topic memory stub

## 项目类型
- 代码项目
- 技能项目
- 文档/研究项目
- 系统项目

## 最小骨架原则
- 保留 README / REPORT 这类核心入口
- 只在确有用途时生成 docs / handoff / topic stub
- 不预设一堆未来可能用不到的空目录

## 默认输出
- 项目骨架摘要
- 已创建文件清单
- 下一步建议
