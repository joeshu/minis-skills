# 压测输出-农村市场作战卡-20260417

## 一、适用场景
适用于：
- 入村活动
- 村委会驻点营销
- 村超 / 村委 / 渠道联动活动
- 农村存量提值 + 异网攻坚 + 宽带 / 移网拉新一体化场景

---

## 二、农村市场稳定打法主骨架
通过本轮农村案例，可以确认农村市场的高价值打法稳定结构为：

1. **驻点 + 上门结合**
2. **村委 / 村超 / 本地渠道协同**
3. **存量精准筛选 + 异网精准打标**
4. **测速 + 算账 + 设备升级 + 融合推荐**
5. **以存拉新、以老带新、业务叠加闭环**

---

## 三、农村市场作战卡（建议版）

### 1. 活动前
- 明确活动驻点（村委会 / 村超周边 / 村内集中区域）
- 梳理目标用户：
  - 流量溢出
  - 语音溢出
  - 合约到期
  - 终端老旧
  - FTTR 潜客
  - 异网目标用户
- 联动村委、渠道、网格、智家工程师提前邀约
- 准备礼品、演示设备、测速工具、对比话术

### 2. 活动中
- 驻点受理 + 上门服务同步推进
- 先做免费测速 / 网络检测 / 资费算账
- 再挖痛点：网速慢、信号盲区、流量不够、孩子上网需求、装修美观等
- 再推方案：
  - 新畅越
  - FTTR
  - 千兆升级
  - 满卡满融
  - 端网业适配
- 对异网用户，坚持融合套餐、满融满配、对比式营销

### 3. 活动后
- 100% 加微信 / 留联系方式
- 对未现场办理用户继续回访
- 对已办理用户强化交付和体验闭环
- 做案例复盘，总结哪类话术、哪类场景最有效

---

## 四、农村市场标准动作
1. 活动前必须有目标用户清单
2. 活动现场必须有驻点和上门两条线
3. 必须有测速、算账、对比三件套
4. 必须把老旧设备替换、WiFi6、FTTR、千兆升级与套餐升级联动讲
5. 必须形成“存量盘活 + 异网迁转 + 新增发展”闭环，不只做单点销售

---

## 五、农村市场关键角色分工
- **网格CEO**：主导用户筛选、活动组织、驻点协调、客户关系维护
- **智家工程师**：测速、设备诊断、现场演示、上门服务、升级转化
- **营业员 / 渠道人员**：现场讲解、优惠说明、受理办理、后续回访
- **村委 / 本地合作渠道**：客情背书、现场组织、熟人信任建立

---

## 六、农村市场高价值话术要点
- 先讲实际问题，不先讲套餐名字
- 先讲省钱 / 解决网速慢 / 覆盖盲区 / 子女上网需求
- 异网用户重点讲“实测效果 + 资费算账 + 熟人背书”
- 农村用户更看重：信任、便利、看得见的实惠、后续有人管

---

## 七、结论
农村市场最有效的不是“大喇叭式宣传”，而是：
**熟人场景 + 驻点服务 + 上门对比 + 存量盘活 + 异网攻坚** 的组合拳。
