## 二、按最新版女娲进行材料分型

### 1. 总经理报告
类型：**战略/会议主线型**
主要强化：
- 高层主线理解
- 宏观经营逻辑转译
- 地市承接语言

### 2. 二季度工作会材料
类型：**战略/会议主线型**
主要强化：
- 联网收入主线
- 细分市场组织打法
- 队伍能力提升
- 执行穿透与日周月节奏

### 3. 市场部总办会汇报
类型：**周汇报/调度型 + 条线统筹型**
主要强化：
- 重点业务 + 细分市场 + 队伍能力并行结构
- 责任领导 / 责任主管 / 本周措施
- 落后单位点评与帮扶机制

### 4. 存量总办会汇报
类型：**周汇报/调度型 + 风险追责型**
主要强化：
- 存量运营三段式
- 本周问题 / 本周措施 / 下周盯控
- 重点单位流失与降套风险识别
- 风险追责与分类管控意识

### 5. 省公司调研汇报（存量）
类型：**对上汇报型**
主要强化：
- 套餐适配主线
- 扩面提能 / 增存一体 / 队伍协同 / 场景转化 / 量质并重
- 做法—成效—问题—下步
- 对上方法论抽象能力

## 三、本轮对技能的真实增量

### 1. 材料分型与任务路由得到真实验证
- 不同材料确实应走不同输出路径
- 不能统一按“材料总结”处理

### 2. 对上 / 对下双向转译能力得到强化
- 二季度工作会材料更偏向“向下拆动作”
- 省公司调研汇报更偏向“向上做抽象”
- 这证明该 Skill 必须同时具备向下与向上的双向表达能力

### 3. 周汇报 / 总办会类材料的重要性进一步提升
真实材料显示：
- 公众线管理的很多关键价值，恰恰不在宏大战略，而在周汇报、总办会、落后单位点评和本周措施里
- 后续应继续把“周汇报/总办会型材料”作为主战材料喂养重点

### 4. 风险追责模块值得继续加厚
存量总办会材料说明：
- 流失、降套、投诉、返销等问题不是附属信息，而是经营质量管理的核心内容
- 后续可继续补更多典型问题追责样本
