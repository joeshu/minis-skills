# 压测输出-市场部总办会材料-20260417

## 一、总体判断
这份材料属于典型的**市场部总办会 / 条线统筹型材料**。

它和一般经营分析材料的区别在于：
- 不是只讲一条线
- 而是要把**重点业务、细分市场、队伍能力、落后单位、责任链条、本周措施**放在一张盘子里统筹起来

所以，这类材料最关键的不是“信息多不多”，而是：
- 重点业务抓得准不准
- 细分市场分得清不清
- 队伍能力提得实不实
- 落后单位点评有没有穿透
- 本周措施能不能压到责任领导 / 责任主管 / 单位 / 一线

---

## 二、按总办会口径重组（建议版）

### （一）当前总体情况
当前市场部工作呈现出“重点业务推进、细分市场攻坚、队伍能力提升、落后单位帮扶”并行推进的特征，具备总办会材料基础，但更应突出问题导向和责任压实，避免只停留在多线并行的动作堆叠。

### （二）重点业务
建议总办会汇报时优先聚焦：
1. 联网收入主线相关重点业务推进情况
2. 满卡满融、融合发展、宽带、FTTR、千兆等核心指标完成情况
3. 对发展质量影响较大的关键风险点，如搭载率不足、转化率偏低、部分单位发展不均衡等

### （三）细分市场
建议按以下结构汇报：
1. 农村市场：是否抓住主战场、标准动作是否清楚
2. 社区市场：是否真正做到了切片细分与场景化组织
3. 商户市场：是否围绕新铺和无宽带商铺形成常态化打法
4. 校园 / 重点场景：是否形成专项协同和重点盯控

### （四）队伍能力
市场部总办会材料不能只讲业务，还要讲队伍：
1. 营业员能力提升是否围绕销售话术、融合转化、千兆升档等核心能力开展
2. 渠道经理是否围绕商户、社区、农村等场景形成标准动作
3. 智家工程师是否真正承担派单转化、随单营销、千兆升级等角色
4. 是否形成破零、达标、帮扶、标杆推广机制

### （五）落后单位点评
总办会汇报时，建议不只报排名，要报：
- 哪些单位落后
- 落后在哪个业务 / 场景 / 指标
- 初步原因是什么
- 责任领导 / 责任主管是谁
- 本周帮扶动作是什么
- 下周是否进入现场帮扶 / 验收 / 专题督办

### （六）本周措施与下周重点
总办会材料必须落到：
1. 本周已做措施
2. 本周措施是否有效
3. 下周重点抓什么
4. 谁来抓
5. 何时见效

## 三、重点业务 + 细分市场 + 队伍能力并行结构（建议模板）

### 1. 重点业务
- 当前业务进度
- 关键短板
- 本周措施
- 下周重点

### 2. 细分市场
- 农村
- 社区
- 商户
- 校园 / 重点场景

每个市场都要回答：
- 当前主攻点是什么
- 动作是否标准化
- 是否能复制推广

### 3. 队伍能力
- 营业员
- 渠道经理
- 智家工程师
- 综合营销经理 / 网格负责人

每类角色都要回答：
- 核心任务是什么
- 当前短板是什么
- 本周训练 / 帮扶 / 督导动作是什么

---

## 四、落后单位点评模板（市场部总办会版）

### 结构
#### 1. 问题点
- 哪个单位落后
- 落后在哪个指标 / 哪个市场 / 哪个环节

#### 2. 原因判断
- 是主战场没找准
- 是动作不标准
- 是责任没压实
- 是队伍能力不足
- 是协同机制缺位

#### 3. 帮扶建议
- 需要谁去现场帮扶
- 需要补什么动作
- 需要补什么能力
- 需要按什么节奏盯控

#### 4. 责任压实
- 责任领导
- 责任主管
- 责任单位
- 本周措施
- 下周验收点

---

## 五、材料质量诊断

### 优点
1. 适合做总办会条线统筹底稿
2. 天然适合重组成“重点业务+细分市场+队伍能力+落后单位点评”结构
3. 很适合继续下沉成责任矩阵和本周措施清单

### 不足
1. 如果只平铺业务，会显得线多而散
2. 如果没有落后单位点评和责任压实，就会变成“条线情况通报”，而不是总办会材料
3. 如果没有本周措施 / 下周重点，就很难形成调度闭环
4. 如果队伍能力只是口号式表述，就会削弱总办会材料的管理价值

### 结论
这类材料最关键的不是多写，而是要把：
**重点业务、细分市场、队伍能力、落后单位点评、责任链条、本周措施**放进同一套结构里。

---

## 六、建议总办会统一追问的五个问题
1. 当前最关键的重点业务卡点是什么？
2. 当前最弱的细分市场在哪里？
3. 哪类队伍能力最短板？
4. 哪些单位需要立即帮扶 / 督办 / 验收？
5. 本周措施能不能在下周看见变化？
