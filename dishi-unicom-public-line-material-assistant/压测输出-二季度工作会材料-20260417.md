# 压测输出-二季度工作会材料-20260417

## 一、总体判断
这份材料属于典型的**战略/会议主线型 + 执行方案型材料**。

它和总经理工作报告相比，更进一步往执行层落了一步，核心价值在于：
- 把主线拆成目标、措施、组织、队伍、节奏
- 更适合直接转成区县承接动作清单

从公众线角度看，最重要的主线是：

> **围绕联网收入增长，按细分市场组织、按三支队伍提能、按新增收入 / 存量收入 / 控降套 / 控流失拆措施，形成“强组织、抓穿透、提产能”的执行体系。**

---

## 二、区县承接动作清单（建议版）

### 1. 先围绕联网收入拉主线
- 每个区县先明确本月联网收入增长主战场
- 不只看发展量，还要拆新增收入、存量收入、控降套、控流失四个模块

### 2. 按细分市场组织动作
- 农村市场：明确两步曲和重点行政村清单
- 社区市场：明确切片细分与物业异业联动清单
- 商户市场：明确新铺和无宽带商铺拓展清单

### 3. 按三支队伍拆责任
- 营业员：融合、套餐适配、进厅转化
- 渠道经理：细分市场拓展、活动组织、触点建设
- 智家工程师：派单营销、随单营销、千兆 / FTTR 升级

### 4. 按日周月抓穿透
- 日：关键指标日盯控
- 周：重点单位、重点场景、重点问题调度
- 月：完成情况、落后原因、责任压实、经验推广

## 三、对技能的增量启发
这份材料进一步说明：
1. 战略主线型材料不只要提炼重点，还要能拆到区县 / 网格 / 角色
2. 这类材料最适合沉淀“战略主线 → 区县承接动作 → 网格 / 角色动作拆解”模板
3. 公众线岗位技能必须同时具备：
   - 高层主线理解能力
   - 中层转译能力
   - 基层动作下沉能力
