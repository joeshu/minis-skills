# REPORT

## 项目名称
地市联通公众线材料助手

---

## 一、项目定位
这是一个面向 **地市联通公众线** 的材料蒸馏与转译 Skill。

它的目标不是泛泛总结材料，而是帮助地市联通公众线人员：
- 看得懂材料
- 提得出重点
- 拆得开动作
- 写得出汇报
- 压得下执行

它已经从单纯“材料摘要助手”，演进为一个更完整的：

**地市联通公众线经营材料助手 + 存量运营专题助手 + 市场部总办会材料助手 + 对上汇报转译助手**

---

## 二、已吸收的核心材料类型

### 1. 省公司年度工作会材料
主要吸收：
- 连接 / 算力 / 服务 / 安全主线
- 创新 / 改革 / 穿透主线
- 宏观经营逻辑与体系化表达

### 2. 地市二季度工作会材料
主要吸收：
- 联网收入主线
- 农村“两步曲”
- 社区“切片细分”
- 商户“新铺+无宽带商铺”
- 三支队伍提能
- 日周月盯控、到网格到人管理

### 3. 存量运营周汇报 / 总办会材料
主要吸收：
- 提价值 / 控降套 / 控流失三段式
- 责任矩阵
- 本周措施 / 下周举措
- 投申诉压降
- 异常降套典型案例追责

### 4. 市场部总办会汇报材料
主要吸收：
- 重点业务 + 细分市场 + 队伍能力并行结构
- 责任领导 / 责任主管 / 本周措施
- 对标先进、落后单位点评
- 分包责任矩阵、现场帮扶、标杆验收

### 5. 面向省公司的调研 / 存量汇报材料
主要吸收：
- 套餐适配为主线
- 扩面提能 / 增存一体 / 队伍协同 / 场景转化 / 量质并重
- 降套减收抓前置维系、分场景管控、穿透执行
- 千兆运营抓入网即千兆、存量升级、用户感知
- 对上汇报中的“做法—成效—问题—下步”表达

## 三、当前沉淀出的核心能力

### 1. 材料解读能力
- 能识别省公司、地市、区县不同层级材料的主线
- 能区分重点要求、原则表述、套话和风险点
- 能从材料中抽出真正可执行的抓手

### 2. 动作拆解能力
- 能把宏观要求下沉成区县动作、网格动作、到岗到人动作
- 能重组为“目标—问题—举措—责任—时限”
- 能形成日 / 周 / 月执行盯控清单

### 3. 专项打法提炼能力
已形成较强识别与转译能力的专项包括：
- 农村市场“两步曲”
- 社区市场“切片细分”
- 商户市场“新铺+无宽带商铺”
- 存量运营“提价值—控降套—控流失”

### 4. 汇报转译能力
- 经营分析提纲
- 总办会口径
- 落后单位点评
- 对上调研汇报
- 方法论抽象表达

### 5. 风险识别与追责复盘能力
- 能识别投诉、退订、异常降套、返销等质量风险
- 能提炼典型案例追责复盘结构
- 能识别“有排名无点评、有措施无责任链条”等常见反模式

---

## 四、当前 Skill 的独特性
与泛“材料总结助手”相比，这个 Skill 的独特性在于：

1. **地市联通味明显**
   - 不是通用咨询风格
   - 有明显的市场部、公众线、存量运营、总办会口径

2. **兼顾两类表达场景**
   - 能写“会上讲的话”
   - 也能写“落地执行的话”

3. **既能向下拆动作，也能向上做抽象**
   - 向下可拆区县 / 网格动作
   - 向上可整理省公司调研汇报口径

4. **有执行感，不只是分析感**
   - 强调责任、节奏、通报、帮扶、追责、复盘

---

## 五、当前边界
当前这版 Skill 仍有以下边界：

1. 不能替代真实经营数据系统
2. 不虚构指标、预算、政策口径、排名数据
3. 对未提供背景的本地经营难题，只做框架判断，不做装懂式结论
4. 对跨专业深度问题（政企、网络、财务、人力）仍需相关条线核实
5. 当前仍主要基于地市公众线与存量材料，对更广的联通全条线覆盖还不完整
