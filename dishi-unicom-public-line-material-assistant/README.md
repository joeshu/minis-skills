# 地市联通公众线材料助手

## 简介
这是一个面向 **地市联通公众线** 的材料蒸馏与转译 Skill。

它的目标不是泛泛总结材料，而是帮助地市联通公众线人员：
- 看得懂材料
- 提得出重点
- 拆得开动作
- 写得出汇报
- 压得下执行

它特别适合处理以下几类材料：
- 省公司年度工作会材料
- 地市季度经营方案
- 存量运营周汇报 / 总办会材料
- 市场部总办会材料
- 落后单位点评材料
- 面向省公司的调研 / 对上汇报材料

---

## 适用对象
- 地市联通总经理 / 副总经理
- 市场部
- 渠道运营
- 区县公司负责人
- 网格负责人
- 公众线专项人员

---

## 核心能力
本 Skill 已沉淀并强化以下能力：

1. **材料解读**
   - 提炼主线
   - 区分重点与套话
   - 识别短板和风险

2. **动作拆解**
   - 将省市材料下沉为区县 / 网格动作
   - 重组为“目标—问题—举措—责任—时限”

3. **专项打法提炼**
   - 农村“两步曲”
   - 社区“切片细分”
   - 商户“新铺+无宽带商铺”
   - 存量运营“提价值—控降套—控流失”

4. **汇报转译**
   - 经营分析会提纲
   - 总办会汇报口径
   - 对上调研汇报口径
   - 落后单位点评

## 使用建议
### 1. 先用真实材料压测
优先测试：
- 五点重点提炼
- 区县承接动作清单
- 日周月执行盯控清单
- 存量周汇报提纲
- 落后单位点评
- 对上汇报提纲

### 2. 继续喂真实材料
如果想进一步增强，优先继续补：
- 地市公众线月度经营分析材料
- 农村 / 社区 / 商户案例材料
- 存量运营专项汇报
- 典型问题追责案例
- 面向省公司的调研汇报材料

---

## 当前边界
本 Skill 当前仍有以下边界：
- 不替代真实经营数据系统
- 不虚构指标、预算、政策口径
- 对未提供背景的本地经营问题，只做框架分析，不做装懂式定量判断
- 对跨专业深度问题（政企、网络、财务、人力）需要结合相关条线进一步核实
- 当前已按最新版女娲补入材料分型、岗位型假像识别、持续喂料与增量更新意识，但这些机制仍需继续通过真实材料压测
