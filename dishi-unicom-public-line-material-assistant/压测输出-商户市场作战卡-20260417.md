# 压测输出-商户市场作战卡-20260417

## 一、适用场景
适用于：
- 商圈走访
- 沿街门店营销
- 新铺开业触达
- 专业市场 / 商场 / 街区活动
- 惠商平台、企业宽带、云智、智家畅越、监控、收银、引流等商户综合方案场景

---

## 二、商户市场稳定打法主骨架
通过本轮 8 份商户案例，可以确认商户市场高价值打法的稳定结构为：

1. **精准摸排 + 一店一策**
2. **网格 / 渠道 / 智家 / 异业合作多方协同**
3. **先服务 / 先诊断 / 先价值展示，再营销转化**
4. **通信产品 + 商户经营需求一体化包装**
5. **活动后回访、加微信、持续运营形成留存与裂变**

---

## 三、商户市场作战卡（建议版）

### 1. 活动前
- 绘制商户地图，按街区 / 社区 / 业态分类管理
- 明确目标商户：
  - 新铺
  - 无宽带商铺
  - 宽带老旧
  - 有监控 / 收银 / 引流需求
  - 套餐不匹配、流量成本高的商户
- 准备“一店一策”方案：
  - 餐饮：千兆宽带 + WiFi6 + 云监控
  - 便利店：宽带 + 惠商平台 + 聚合收款 / 引流能力
  - 夫妻店 / 夜间营业店：监控 + 宽带 + 惠企卡 / 融合方案
- 做晨会定目标、夕会复盘问题

### 2. 活动中
- 先做服务与破冰：
  - 购物 / 聊生意 / 检测速 / 看收银 / 看监控 / 看引流痛点
- 再挖经营痛点：
  - 客源少
  - 宣传难
  - 监控成本高
  - 网速慢影响收银 / 外卖 / 顾客体验
  - 手机流量使用多、资费高
- 再给综合方案：
  - 平台 + 套餐
  - 宽带 + 卡 + 监控
  - 收款 / 引流 / 视频彩铃 / 商机通等经营赋能能力
- 现场能办就办，不能办就拉意向群、加微信、留台账

### 3. 活动后
- 100% 加微信
- 对意向商户及时回访
- 对已办理商户做好安装、平台辅导和使用指导
- 引导老商户带新商户，形成裂变
- 每月回访商户，继续推荐升级和新增业务

---

## 四、商户市场标准动作
1. 活动前必须有商户地图和目标清单
2. 必须准备“一店一策”方案，而不是一套话术打全部
3. 必须先看商户经营痛点，再推通信产品
4. 必须把通信产品和经营赋能打包讲，而不是只讲资费
5. 必须活动后持续回访，不做“一锤子买卖”

---

## 五、关键角色分工
- **网格人员 / 网格CEO**：商户摸排、主导走访、方案组织、台账管理
- **渠道经理 / 营业员**：商户触达、话术讲解、活动执行、回访转化
- **智家工程师**：测速、网络诊断、设备演示、安装交付、专业背书
- **异业合作方 / 社会渠道**：人力协同、场景协同、引流协同、市场背书

---

## 六、商户市场核心话术原则
- 不先讲套餐，先讲经营问题
- 不只讲便宜，重点讲：
  - 引流
  - 监控
  - 收银体验
  - 客户到店感知
  - 经营效率
- 让商户感觉联通不是“卖卡卖宽带”，而是在帮他解决经营问题

---

## 七、结论
商户市场最有效的不是“扫街式推销”，而是：
**精准摸排 + 一店一策 + 经营问题切入 + 综合方案打包 + 持续回访留存**。
