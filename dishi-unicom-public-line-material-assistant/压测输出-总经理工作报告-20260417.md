# 压测输出-总经理工作报告-20260417

## 一、总体判断
这份总经理工作报告属于典型的**战略/会议主线型材料**。

它的核心价值不在于逐段复述，而在于：
- 抽出真正的经营主线
- 分清战略要求、经营要求、管理要求
- 把省公司/高层话语转成地市、区县、网格能承接的动作语言

从公众线角度看，这份报告最重要的主线可以压缩成：

> **围绕市场地位提升，聚焦“连接、算力、服务、安全”核心赛道，以创新、改革、穿透三条主线，推动公众线规模增长、存量提值、细分市场突破和执行穿透能力提升。**

---

## 二、公众线最相关的五个核心重点

### 1. 市场地位提升是总目标，公众线是主战场
报告明确把“提升市场地位”“份额突破”放在核心位置，对公众线来说，意味着不能只看发展量，更要看：
- 份额
- 渗透率
- 用户规模
- 客户价值

### 2. 公众线要靠细分市场破局
报告中对公众线最有价值的部分，是明确指出：
- 农村市场继续做深
- 商户市场继续做强
- 社区市场重点突破
- 校园市场保持优势
- 存量市场持续做价值经营

这说明公众线经营必须继续走“分市场、分打法、分责任”的路线。

### 3. 存量经营被抬到更高位置
报告明确提出：
- 套餐适配
- 端网业适配
- 满卡满融
- 千兆 / 云智升级
- 智慧大脑和工具赋能

这说明存量经营已不是配角，而是提升联网收入和客户价值的重要抓手。

### 4. 宽带为核心的市场体系和自控队伍为核心的营服组织体系是重要组织抓手
这不是一句口号，而是公众线工作的组织要求：
- 业务要围绕宽带核心重构
- 队伍要围绕自控、自有、可穿透来建
- 一线工具和后台赋能都要服务于这一体系

### 5. “穿透”不是作风词，而是管理动作要求
报告中的“穿透”对公众线来说，不能停留在表态，必须理解成：
- 指令传递穿透
- 责任链条穿透
- 数据能力穿透
- 考核评价穿透
- 到区县、到网格、到岗位、到日周月的执行穿透

## 三、区县承接动作清单（建议版）

### （一）围绕市场地位提升抓份额和价值
1. 每个区县明确公众线主战市场（农村 / 社区 / 商户 / 校园 / 存量）
2. 每月不仅看发展量，还看份额、渗透率、价值提升
3. 对弱势市场建立专项突破清单

### （二）围绕细分市场抓打法落地
1. 农村市场：继续做“1+3+N”模式和利益共同体拓展
2. 商户市场：围绕新铺、无宽带商铺、行业场景做标准化动作
3. 社区市场：推进物业+异业双驱动，做深社区触点
4. 校园市场：做实前置触点和2B带2C协同

### （三）围绕存量经营抓价值提升
1. 抓套餐适配
2. 抓端网业适配
3. 抓满卡满融
4. 抓千兆升级
5. 抓高风险用户维系和流失回捞

### （四）围绕营服体系抓队伍建设
1. 营业员：提升融合、千兆、套餐适配能力
2. 渠道经理：提升场景化拓展和标准动作执行能力
3. 智家工程师：提升随单营销、派单转化、升级转化能力
4. 网格负责人：提升属地宽带经营和日周月盯控能力

### （五）围绕执行穿透抓日周月节奏
1. 日：关键指标日通报
2. 周：重点单位、重点问题、重点动作周调度
3. 月：目标完成、问题复盘、责任压实、经验推广

## 四、网格 / 角色动作拆解（建议版）

### 网格负责人
- 明确主战市场
- 每周梳理重点客群、重点场景、重点问题
- 盯网格宽带发展、存量提值、风险用户维系

### 营业员
- 重点承接融合发展、套餐适配、千兆升级
- 强化标准销售话术和进厅转化

### 渠道经理
- 重点承接商户、社区、农村触点拓展
- 抓渠道动员、清单盯控、活动组织

### 智家工程师
- 重点承接派单营销、随单营销、千兆 / FTTR 升级
- 做好安装交付与升级转化协同

3. 一些指标和要求还需要继续压成更适合执行层的表达

这份材料非常适合作为“战略主线型材料”的母本，最佳使用方式不是摘抄，而是：
**抽主线—拆动作—压责任—定节奏。**
