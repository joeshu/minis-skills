# memory-system-git-sync 执行样本记录模板

用途：记录一次真实同步/恢复过程，作为回归验证样本。

## 建议记录字段
- 日期
- 模式（check / sync / push / restore）
- 同步范围
- 是否发现敏感信息
- 是否发现无关改动
- 是否成功刷新镜像
- 是否成功提交/推送
- 是否成功恢复框架
- 是否采用增量恢复
- 结果质量评估
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 模式：check / sync / push / restore
- 同步范围：
- 是否发现敏感信息：是 / 否
- 是否发现无关改动：是 / 否
- 是否成功刷新镜像：是 / 否
- 是否成功提交/推送：是 / 否
- 是否成功恢复框架：是 / 否
- 是否采用增量恢复：是 / 否
- 结果质量评估：好 / 一般 / 差
- 备注：
```
