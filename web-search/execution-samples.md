# web-search 浏览器执行样本记录模板

用途：记录一次真实浏览器搜索过程，作为后续 full test / 回归测试样本。

## 建议记录字段
- 日期
- 用户原始问题
- 判定意图
- 初始引擎链路
- 实际首选引擎
- 是否发生 fallback
- fallback 原因
- 是否补第二来源
- 最终使用的来源
- 输出风格
- 结果质量评估
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 用户原始问题：
- 判定意图：
- 初始引擎链路：
- 实际首选引擎：
- 是否发生 fallback：是 / 否
- fallback 原因：
- 是否补第二来源：是 / 否
- 最终使用的来源：
- 输出风格：普通搜索 / 对比 / 官网查找 / 失败说明
- 结果质量评估：好 / 一般 / 差
- 备注：
```

## 评分用途
后续可据此观察：
- 哪些意图最常触发 fallback
- 哪些引擎最稳定
- 哪些场景最需要第二来源
- 输出风格是否符合预期
