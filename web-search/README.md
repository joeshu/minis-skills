# web-search

用途：联网搜索实时信息，并在引擎失效或结果差时自动切换。

## 一眼判断
- 要中文总结：先 `秘塔AI / Perplexity`
- 要官网 / 原文 / 下载入口：先 `Google / Bing`
- 要通用网页搜索：`Google / Bing / Brave`
- 要隐私优先：`Brave / DuckDuckGo`

## 默认行为
- 默认先给短结论
- 默认给 1~3 个来源
- 当前引擎失效时自动 fallback
- 结果冲突时建议补一个来源交叉验证

## 搜索链路
- 深度研究：`Perplexity -> 秘塔AI -> Bing -> Google -> Brave`
- 中文搜索：`秘塔AI -> Perplexity -> 百度 -> Bing -> Google`
- 官网查找：`Google -> Bing -> Brave -> DuckDuckGo`
- 隐私优先：`Brave -> DuckDuckGo -> Bing`

## 何时切换引擎
- 未登录
- 验证码 / 异常流量
- 空结果
- 回到首页
- 结果偏题
- 页面提取不到有效内容

## 输出风格
- 普通搜索：结论 + 来源
- 多来源对比：结论 + 差异点
- 官网查找：官方入口优先
- 搜索失败：失败说明 + 下一步建议

## 第二来源补充规则
以下情况建议补第二来源：
- 实时新闻 / 政策 / 价格 / 版本变化
- 对比、趋势、现状判断
- 中文结果噪声较高
- 用户明确要求多来源
- 结果彼此可能冲突
- 代码 / API / SDK / 开发文档搜索

## 第二来源怎么选
- 新闻/公告：优先补官方公告或另一家媒体
- 官网/文档：优先补另一搜索引擎验证同一官方入口
- 中文结果：优先补 Bing / Google 交叉验证
- 代码/开发文档：优先补官方文档、官方仓库、release note、issue，不用两个二手教程互证

## 引擎异常模式速查
- Perplexity：登录失效 / 只剩摘要无来源
- 秘塔AI：停在首页 / 结果页加载异常
- Google：官网查询偏题 / 页面不可用
- DuckDuckGo：异常页 / 结构化信息少
- 百度搜狗：中文强但噪声偏多

## 响应模板
- 普通搜索：一句结论 + 1~3 来源
- 多来源对比：一句总结 + 主要差异 + 来源
- 官网查找：先给官方入口，再补一句判断依据
- 失败：先说明失败，再说明是否已切备用源
