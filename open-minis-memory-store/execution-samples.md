# open-minis-memory-store 执行样本记录模板

用途：记录一次真实记忆归并过程，作为回归验证样本。

## 建议记录字段
- 日期
- 主题
- 相关关键词
- 是否已有主记忆
- 检索到的相关记忆数量
- 分类结果（重复 / 过时 / 保留观察）
- 是否先备份
- 是否实际删除旧项
- 最终主记忆结果
- 结果质量评估
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 主题：
- 相关关键词：
- 是否已有主记忆：是 / 否
- 检索到的相关记忆数量：
- 分类结果：
- 是否先备份：是 / 否
- 是否实际删除旧项：是 / 否
- 最终主记忆结果：
- 结果质量评估：好 / 一般 / 差
- 备注：
```
