# memory-topic-router

用途：当任务命中某个项目、站点、工作流、方法论或高频来源时，优先读取 `/var/minis/shared/memory_topics/` 下的专题记忆文件，再按需回退到 `GLOBAL.md` 和 daily memory。

## 默认顺序
1. 专题记忆
2. `GLOBAL.md`
3. daily memory

## 什么时候优先查专题
- 明确说出项目名 / 站点名 / 工作流名
- 任务语义明显属于某长期主题
- 命中稳定路径、固定平台、固定来源
- 命中方法论主题（如记忆维护、skill 设计、本地化）

## 专题不足时回退
- 专题文件不存在
- 专题文件内容不足
- 需要跨主题总原则
- 需要近期变动信息

## 专题命名与维护
- 项目专题按项目名命名
- 平台专题按平台/站点名命名
- 工作流专题按流程名命名
- 方法论专题按方法论主题命名
- 稳定长期规则优先进专题
- 跨主题长期原则进 `GLOBAL.md`
- 近期变化先进 daily memory
- 同一主题尽量只保留一个主专题文件

## 多候选专题处理
- 默认先读最具体的专题
- 优先级：项目 > 工作流 > 平台 > 方法论
- 如仍不足，再补读更上层专题

## 冲突规则
- 当前用户要求优先
- 若与专题规则冲突，可先按当前要求执行，再视情况更新专题或 daily memory
