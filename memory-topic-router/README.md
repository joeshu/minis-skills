# memory-topic-router

用途：当任务命中某个项目、站点、工作流、方法论或高频来源时，优先读取 `/var/minis/shared/memory_topics/` 下的专题记忆文件，再按需回退到 `GLOBAL.md` 和 daily memory。

## 默认顺序
1. 专题记忆
2. `GLOBAL.md`
3. daily memory

## 什么时候优先查专题
- 明确说出项目名 / 站点名 / 工作流名
- 任务语义明显属于某长期主题
- 命中稳定路径、固定平台、固定来源
- 命中方法论主题（如记忆维护、skill 设计、本地化）

## 回退条件
- 专题文件不存在
- 专题文件内容不足
- 需要跨主题总原则
- 需要近期变动信息

## 专题类型
- 项目专题：项目内长期约定
- 站点/平台专题：某站点或平台的长期规则
- 工作流专题：固定执行流程
- 方法论专题：跨项目的方法论规则

## 维护原则
- 专题文件存稳定知识
- `GLOBAL.md` 存跨主题总原则
- daily memory 存近期变化
- 当前用户要求优先于历史专题规则
