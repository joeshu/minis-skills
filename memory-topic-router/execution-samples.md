# memory-topic-router 执行样本记录模板

用途：记录一次真实“专题优先记忆检索”过程，作为回归验证样本。

## 建议记录字段
- 日期
- 用户原始请求
- 命中类型（项目 / 平台 / 工作流 / 方法论 / 无专题）
- 是否命中专题文件
- 命中的专题路径
- 是否回退到 GLOBAL.md
- 是否回退到 daily memory
- 当前用户要求是否覆盖旧专题规则
- 最终采用的记忆来源顺序
- 结果质量评估
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 用户原始请求：
- 命中类型：项目 / 平台 / 工作流 / 方法论 / 无专题
- 是否命中专题文件：是 / 否
- 命中的专题路径：
- 是否回退到 GLOBAL.md：是 / 否
- 是否回退到 daily memory：是 / 否
- 当前用户要求是否覆盖旧专题规则：是 / 否
- 最终采用的记忆来源顺序：
- 结果质量评估：好 / 一般 / 差
- 备注：
```
