说明：当前环境未启用独立子 agent 自动双跑，因此本报告采用 **with-skill vs baseline 的人工对照法**。本轮重点验证：专题优先命中、语义/站点/路径/工作流关联、回退顺序、方法论专题、以及当前用户要求覆盖旧专题规则。

## 一、测试样例覆盖

1. 明确项目命中专题

4. 方法论专题命中
5. 当前用户要求覆盖旧专题规则
6. 平台/站点专题命中

## 二、with-skill vs baseline 对照

### Case 1：明确项目命中专题
**Prompt**：继续处理 UnifiedVIP 项目，先按这个项目过去的约定来。

**Baseline（不带 skill）预期表现**：
- 可能直接去 daily memory 搜关键词
- 不一定优先考虑专题记忆文件

**With Skill 预期表现**：
- 识别为显式项目命中
- 优先查 `/var/minis/shared/memory_topics/` 下对应专题文件
- 不先跳到 daily memory

**结果判定**：with-skill 明显优于 baseline

---

### Case 2：工作流语义命中专题
**Prompt**：帮我继续做 GitHub 仓库同步这套流程。

**Baseline（不带 skill）预期表现**：
- 可能只做一般记忆检索
- 不一定意识到这属于工作流专题

**With Skill 预期表现**：
- 即使用户未直说专题名，也能识别工作流关联
- 优先考虑工作流专题文件

**结果判定**：with-skill 明显优于 baseline

---

### Case 3：未命中专题时回退
**Prompt**：这个任务看起来没有明确专题，你按一般记忆规则查就行。

**Baseline（不带 skill）预期表现**：
- 可以正常检索，但不一定明确层级顺序

**With Skill 预期表现**：
- 识别未命中专题
- 回退到 `GLOBAL.md` / daily memory
- 不强行套专题规则

**结果判定**：with-skill 优于 baseline

---

### Case 4：方法论专题命中
**Prompt**：这次是记忆系统维护，先看方法论相关的长期规则。

**Baseline（不带 skill）预期表现**：
- 可能只做泛化记忆检索
- 不一定优先方法论专题

**With Skill 预期表现**：
- 识别为方法论主题
- 优先读取对应方法论专题文件

**结果判定**：with-skill 明显优于 baseline

---

### Case 5：当前用户要求覆盖旧专题规则
**Prompt**：虽然这个专题以前是这么做的，但这次按我现在说的来。

**Baseline（不带 skill）预期表现**：
- 可能仍被旧记忆牵制
- 不一定明确当前用户要求优先

**With Skill 预期表现**：

---

### Case 6：平台/站点专题命中
**Prompt**：这个任务和 GitHub 平台规则明显相关，你先看对应长期专题。

**Baseline（不带 skill）预期表现**：

- 不一定把平台专题独立出来

**With Skill 预期表现**：

- 优先查平台专题文件

**结果判定**：with-skill 明显优于 baseline

## 三、实测表现评分（维度 8）

### 评分依据
- 是否优先查专题记忆
- 是否能在用户未直说专题名时识别语义关联
- 是否能区分专题 / GLOBAL / daily 的边界
- 是否在当前用户要求冲突时优先遵循当前指令
- 是否减少无关记忆噪音

### 评分结论
**维度 8（实测表现） = 9.5 / 10**

理由：
- 6 类关键场景下，with-skill 全部优于 baseline
- 该技能显著降低了“直接搜 daily memory”的噪音风险
- 站点/方法论/工作流这些隐性专题都被纳入考虑

未给到更高分的原因：
- 当前仍没有真实专题文件样本库可回归验证
- 仍是人工 full-test style，不是自动双跑
