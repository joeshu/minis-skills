说明：当前环境未启用独立子 agent 自动双跑，因此本报告采用 **with-skill vs baseline 的人工对照法**。本轮重点验证：专题优先命中、匹配优先级、专题不足判定、回退顺序、维护去向规则，以及当前用户要求覆盖旧专题规则。
