# memory-topic-router Full Test 评分报告

评估时间：2026-04-15
评估模式：**full-test style（人工对照评估）**
说明：当前环境未启用独立子 agent 自动双跑，因此本报告采用 **with-skill vs baseline 的人工对照法**。本轮重点验证：专题优先检索、匹配优先级、多候选专题处理、专题不足判定、维护去向规则，以及和其他记忆技能的边界分工。

---

## 一、测试样例覆盖
本轮覆盖 10 类关键场景：
1. 明确项目命中专题
2. 工作流语义命中专题
3. 未命中专题时回退
4. 方法论专题命中
5. 当前用户要求覆盖旧专题规则
6. 平台/站点专题命中
7. 专题不足后回退
8. 临时变化写入 daily
9. 多候选专题优先最具体者
10. 跨主题长期原则进入 GLOBAL.md

---

## 二、with-skill vs baseline 对照

### Case 1：明确项目命中专题
**Prompt**：继续处理 UnifiedVIP 项目，先按这个项目过去的约定来。

**Baseline（不带 skill）预期表现**：
- 可能直接搜索 daily memory
- 不一定优先项目专题文件

**With Skill 预期表现**：
- 识别为显式项目命中
- 优先查 `/var/minis/shared/memory_topics/` 项目专题文件

**结果判定**：with-skill 明显优于 baseline

---

### Case 2：工作流语义命中专题
**Prompt**：帮我继续做 GitHub 仓库同步这套流程。

**Baseline（不带 skill）预期表现**：
- 可能只做一般记忆检索
- 不一定把它识别成工作流专题

**With Skill 预期表现**：
- 识别语义层面的工作流命中
- 优先考虑工作流专题文件

**结果判定**：with-skill 明显优于 baseline

---

### Case 3：未命中专题时回退
**Prompt**：这个任务看起来没有明确专题，你按一般记忆规则查就行。

**Baseline（不带 skill）预期表现**：
- 可以检索，但不一定有清晰层级顺序

**With Skill 预期表现**：
- 明确未命中专题
- 回退到 `GLOBAL.md` / daily memory
- 不强行套专题规则

**结果判定**：with-skill 优于 baseline

---

### Case 4：方法论专题命中
**Prompt**：这次是记忆系统维护，先看方法论相关的长期规则。

**Baseline（不带 skill）预期表现**：
- 可能只做泛化记忆搜索

**With Skill 预期表现**：
- 识别为方法论专题
- 优先查对应专题文件

**结果判定**：with-skill 明显优于 baseline

---

### Case 5：当前用户要求覆盖旧专题规则
**Prompt**：虽然这个专题以前是这么做的，但这次按我现在说的来。

**Baseline（不带 skill）预期表现**：
- 可能仍被旧专题规则牵引

**With Skill 预期表现**：
- 明确当前用户要求优先
- 必要时建议更新专题或 daily memory

**结果判定**：with-skill 显著优于 baseline

---

### Case 6：平台/站点专题命中
**Prompt**：这个任务和 GitHub 平台规则明显相关，你先看对应长期专题。

**Baseline（不带 skill）预期表现**：
- 可能只按关键词检索
- 不一定独立识别平台专题

**With Skill 预期表现**：
- 识别为站点/平台专题
- 优先查平台专题文件

**结果判定**：with-skill 明显优于 baseline

---

### Case 7：专题不足后回退
**Prompt**：这个专题文件只有背景介绍，没有当前执行规则，你继续补查其他记忆。

**Baseline（不带 skill）预期表现**：
- 可能停留在专题文件
- 不一定知道何时算“专题不足”

**With Skill 预期表现**：
- 能用专题不足判定标准判断不够用
- 启动 `GLOBAL.md` / daily memory 回退

**结果判定**：with-skill 显著优于 baseline

---

### Case 8：临时变化写入 daily
**Prompt**：这个新规则只是最近一次临时变化，先别升格成专题长期规则。

**Baseline（不带 skill）预期表现**：
- 可能直接建议更新专题

**With Skill 预期表现**：
- 识别为近期变化
- 优先写入 daily memory
- 不急于升格为专题规则

**结果判定**：with-skill 显著优于 baseline

---

### Case 9：多候选专题优先最具体者
**Prompt**：这里同时像项目专题也像 GitHub 工作流专题，你先读最具体的那个。

**Baseline（不带 skill）预期表现**：
- 可能随机挑一个专题
- 不一定知道“项目 > 工作流 > 平台 > 方法论”的优先级

**With Skill 预期表现**：
- 识别多候选专题
- 优先读取最具体的专题
- 必要时再补读上层专题

**结果判定**：with-skill 显著优于 baseline

---

### Case 10：跨主题长期原则进入 GLOBAL.md
**Prompt**：这个规则是跨项目长期通用原则，不要写到某个专题文件里。

**Baseline（不带 skill）预期表现**：
- 可能仍然建议写进专题

**With Skill 预期表现**：
- 识别为跨主题长期原则
- 优先建议写入 `GLOBAL.md`

**结果判定**：with-skill 显著优于 baseline
