# memory-system-maintainer 执行样本记录模板

用途：记录一次真实记忆系统治理过程，作为回归验证样本。

## 建议记录字段
- 日期
- 用户原始请求
- 问题类型
- 首选子技能
- 是否触发组合流程
- 组合顺序
- 最终结果
- 是否成功减少噪音/冲突
- 结果质量评估
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 用户原始请求：
- 问题类型：写入 / 读取 / 审计 / 归并 / 全局维护
- 首选子技能：
- 是否触发组合流程：是 / 否
- 组合顺序：
- 最终结果：
- 是否成功减少噪音/冲突：是 / 否
- 结果质量评估：好 / 一般 / 差
- 备注：
```
