# open-minis-skill-lifecycle-manager 执行样本模板

用途：记录技能从某个生命周期阶段推进到下一阶段的真实案例。

## 建议记录字段
- 日期
- 技能名
- 初始阶段
- 用户目标
- 缺失资产
- 采取路线（A/B/C/D/E/F）
- 实际补齐内容
- 是否进入发布态
- 是否进入维护态
- 是否进入 freeze 倾向
- 结果评估
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 技能名：
- 初始阶段：新建 / 半成品 / 可用 / 已发布 / 维护态
- 用户目标：上线 / 冲高分 / 修边界 / 回归 / 封板 / freeze 判断
- 缺失资产：
- 采取路线：A / B / C / D / E / F
- 实际补齐内容：
- 是否进入发布态：是 / 否
- 是否进入维护态：是 / 否
- 是否进入 freeze 倾向：是 / 否
- 结果评估：好 / 一般 / 差
- 备注：
```
