# github-sync-helper 执行样本记录模板

用途：记录一次真实 Git / GitHub 操作过程，作为 full test 与回归验证样本。

## 建议记录字段
- 日期
- 用户原始请求
- 操作类型
- 风险等级
- 是否确认
- 当前仓库状态
- 实际执行命令
- 是否需要 GITHUB_TOKEN
- 最终结果
- 是否成功
- 失败原因（如有）
- 下一步建议
- 备注

## 样本模板
```md
### Sample N
- 日期：YYYY-MM-DD
- 用户原始请求：
- 操作类型：
- 风险等级：low / medium / high
- 是否确认：是 / 否
- 当前仓库状态：
- 实际执行命令：
- 是否需要 GITHUB_TOKEN：是 / 否
- 最终结果：
- 是否成功：是 / 否
- 失败原因：
- 下一步建议：
- 备注：
```

## 评估用途
后续可据此观察：
- 哪些操作最容易出错
- 哪些高风险确认最常被触发
- 哪些 API 操作最依赖 token
- 哪些复杂冲突场景需要继续细化
